# 📝 Go Todo API

A simple RESTful Todo API built with **Go (Golang)** and the **Gin Web Framework**.

This project demonstrates the fundamentals of building a backend REST API in Go, including routing, JSON handling, creating todos, retrieving todos, and retrieving a todo by its ID.

---

## 🚀 Features

- ✅ Get all todos
- ✅ Create a new todo
- ✅ Get a single todo by ID
- ✅ JSON request and response handling
- ✅ HTTP status codes
- ✅ Gin routing
- ✅ In-memory todo storage

---

## 🛠️ Technologies Used

- **Go (Golang)**
- **Gin**
- **REST API**
- **JSON**
- **HTTP**
